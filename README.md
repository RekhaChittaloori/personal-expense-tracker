# 💰 Personal Expense Tracker

<p align="center">
  <b>Track Smart. Spend Wise. Save More! 🚀</b>
</p>

A simple **Core Java** console-based application to manage daily expenses, track spending, and maintain budgets.

## ✨ Features

- ➕ Add and record expenses
- 📋 View all expenses
- 🗂️ Filter expenses by category
- 🎯 Set and manage budgets
- 📊 View expense summaries
- 📁 Save expense reports

## 🛠️ Tech Stack

- ☕ Java (Core Java)
- 🧩 Object-Oriented Programming
- 📚 Java Collections
- ⚠️ Exception Handling
- 💻 Eclipse IDE

## 🚀 How to Run

1. Clone this repository.
2. Import the project into Eclipse IDE.
3. Open `Main.java`.
4. Run as **Java Application**.
